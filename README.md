# DreamPitch

Premium cinematic interactive sales deck for American Dream Mall.

## Tech Stack

- Next.js 14 App Router
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide React

## Features

- Luxury cinematic UI
- Glassmorphism cards
- Responsive layouts
- Smooth scrolling
- Animated transitions
- Interactive sections
- Optimized performance

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

Optimized for Vercel deployment.
